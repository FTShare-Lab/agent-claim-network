# Landing fonts

Landing 自托管以下 Google Fonts Latin 可变字体：

- `jetbrains-mono-latin-wght.woff2`：JetBrains Mono，ID / 时间 / 代码等使用 400–700 字重。

标题、正文与中文均使用 CSS 中声明的系统无衬线字体，不依赖额外字体文件。字体文件来自 Google Fonts 提供的 WOFF2 webfont；上游字体与许可证见：

- <https://github.com/google/fonts/tree/main/ofl/jetbrainsmono>

该字体按 SIL Open Font License 1.1 分发，对应许可文本保存在 `OFL-jetbrains-mono.txt`。它只覆盖拉丁字符；Landing 中的中文继续使用系统字体回退。
