# TUI 输入框导航、斜杠菜单与行内补全

> 状态：已实现。本文保留 composer 导航、命令菜单与补全语义。

## 背景与目标

长输入需要在不离开输入框的前提下快速定位和修改。TUI 同时需要把已加载的用户 skill 与原生 slash command 放在统一入口中，并在正文内提供低干扰的唯一前缀补全。

本需求只定义输入框的导航、候选展示与补全语义；不改变 skill 的加载、执行和权限机制。

目标：

- 仅用 Option 加左右方向键按词移动光标，并正确处理中文和 ACN 生成的可见占位符。
- 在行首 slash 菜单中先展示已加载的用户 skill，再展示原生 slash command。
- 支持候选选择、前缀补全，以及正文中的唯一 slash 前缀补全。

## 范围与术语

- **原生命令**：TUI 已支持的 `/compact`、`/copy`、`/exit`、`/help`、`/inbox`、`/mcp`、`/ps`、`/resume`、`/skills`。
- **可补全 skill**：已加载且名称仅由 ASCII 字母、数字、`-`、`_` 组成的用户 skill。该限制只约束 slash 候选，不影响 skill 本身的加载和使用。
- **词**：连续的字母、数字或 `_`；连续中文字符属于同一词。空白、换行、`/`、`@`、`-` 等是边界；数字内的 `.`、`,` 与字母内的 `'` 保持在同一词内。
- **ACN 占位符**：`[Pasted Content <n> chars]`、`[Pasted Content <n> chars #<n>]` 与 `[Image #<n>]`。

## 用户行为

### Option 词级移动

- 只有修饰键恰好为 Option 的 `Option+←` 与 `Option+→` 触发词级移动。
- 终端把这两个按键编码为 `Option+b` 或 `Option+f` 时，分别等同于 `Option+←` 与 `Option+→`。
- `Ctrl+←/→`、`Shift+Option+←/→`、`Ctrl+Option+←/→` 及其他叠加修饰键不得触发词级移动，仍走普通方向键处理。
- 向左移动到当前词首；向右移动到下一个词首；没有可达词边界时移动到输入开头或结尾。
- 词级移动不得停在 ACN 占位符内部；跨越占位符时必须一次跳过整个占位符。
- 普通单字符方向键仍可进入占位符文本；本需求只定义 Option 词级移动的原子跨越规则。

### 行首斜杠菜单

- 当整个输入是以 `/` 开头、无空白与换行的合法前缀，且尚未精确匹配某个候选时，显示 slash 菜单。
- 菜单候选顺序固定为：可补全 skill 按名称字母序在前，原生命令按名称字母序在后。
- 同名 skill 不重复展示；与原生命令同名的 skill 不进入菜单，原生命令保持唯一候选。
- 菜单默认最多显示 5 项。`↑`、`↓` 循环改变选中项；选中项离开可见窗口时，窗口随之滚动，且始终保持 5 项上限。
- 输入 `/tui-` 等前缀时，只显示以该前缀开头的候选。
- 菜单可见时，`Tab` 或 `Enter` 只将当前选中候选写入输入框，不提交。补全后的下一次 `Enter` 才按既有输入提交规则处理。
- 精确匹配的用户 skill 作为普通用户输入提交给既有 skill 机制；菜单补全不得自动执行 skill。

### 行内唯一前缀补全

- 光标位于输入末尾，且最后一个空白字符后的 token 是 `/` 开头的合法前缀时，系统检查全部 slash 候选。
- 只有恰好存在一个候选、且该 token 仍缺少后缀时，才在输入文本后以弱化颜色显示缺失后缀。
- `Tab` 接受该弱化后缀；不存在唯一候选、输入已精确完整、光标不在输入末尾或没有前置空白时，不显示也不接受行内补全。
- 行内补全不显示候选菜单，不改变普通文本输入、提交或队列语义。

## 约束

- 词级移动使用 Unicode 文本边界；不引入词典式中文分词，也不对业务术语作特殊拆分。
- slash 菜单与行内补全使用同一候选集合，避免展示结果与可补全结果不一致。
- 菜单打开时，方向键、`Tab` 与 `Enter` 优先服务菜单；菜单关闭后，`Tab` 才可接受行内唯一补全。
- 候选描述只能辅助识别，不影响排序、匹配、唯一性判断或提交内容。

## 非目标

- 不为包含中文、`.`、空白或 `/` 的 skill 名称新增 slash 补全语法。
- 不新增按词删除、选区扩展、自动提交或自动执行能力。
- 不改变 Home、End、Command、Fn、Ctrl 等快捷键的既有语义。
- 不改变 skill 的加载路径、权限、执行机制或原生命令的业务语义。

## 验收标准

- 在含空白、`/`、`@`、连续中文和中英文相邻文本的输入中，Option 词级移动落点符合“词”定义。
- `[Pasted Content …]` 与 `[Image #…]` 在 Option 词级移动中始终被整体跨越，光标不落在其内部。
- `Ctrl+Option+←/→` 与 `Shift+Option+←/→` 不触发词级移动。
- 行首输入 `/` 时，已加载的可补全 skill 全部位于原生命令之前，两个分组内均按字母序排列。
- 候选超过 5 项时，首屏最多显示 5 项；连续使用 `↑`、`↓` 可以使后续候选进入视野。
- skill 的半截前缀可通过 `Tab` 和 `Enter` 补全；第一次 `Enter` 不提交，第二次 `Enter` 才提交。
- 正文中输入“空白 + `/` + 唯一前缀”时显示弱化后缀，`Tab` 后输入变为完整候选；歧义前缀、完整名称和中间光标位置均不显示提示。
